# Project Plan

## Objective

Build an end-to-end AI application that classifies customer support tickets.

## Week 1 Scope

- Set up the GitHub repository
- Select a public support-ticket dataset
- Load and prepare data using Snowflake
- Train a baseline NLP classification model
- Build a FastAPI prediction endpoint
- Build a Streamlit dashboard
- Add testing and documentation

## Planned Technology Stack

- Python
- pandas
- scikit-learn
- Snowflake
- FastAPI
- Streamlit
- Plotly
- pytest
- Docker

## Initial Prediction Target

Predict the category of a customer support ticket from its subject and description.

## Future Enhancements

- Priority prediction
- Escalation prediction
- Model monitoring
- Cloud deployment
- CI/CD using GitHub Actions

# AI Support Ticket Intelligence

An end-to-end Applied AI project that classifies customer support tickets using Python, machine learning, Snowflake, FastAPI, and Streamlit.

## Planned Features

- Ticket category classification
- Snowflake-based data preparation
- FastAPI prediction service
- Streamlit dashboard
- Model evaluation and monitoring
- Dockerized deployment
